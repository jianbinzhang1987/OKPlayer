## 3. 当前基线与已确认事实

### 3.1 当前产品基线

当前应用已经具备：

- 多配置和多播放源管理；
- 首页、片库、搜索、详情；
- 收藏、历史、断点续播；
- 内置播放器和 mpv 兼容播放；
- CatVod Node 服务；
- 网盘相关运行时和配置中心；
- 来源质量检测和异常记录；
- 多来源搜索和跨配置来源引用。

### 3.2 当前搜索问题事实

已验证当前选中的“至臻”来源直接搜索“庆余年”可以返回：

- 《庆余年 第一季》；
- 《庆余年 第二季》。

说明当前来源搜索接口本身可用。当前界面“搜索不到”更可能来自：

- 默认搜索全部配置源；
- 历史配置和异常来源过多；
- 当前 CatVod 来源未被优先执行；
- 全局搜索没有真正增量返回；
- 空结果页面没有展示各来源失败原因。

### 3.3 当前来源质量数据概况

来源质量必须区分三类事实：

- 当前桌面端无法执行的 Android Dex/JAR 或未知运行时：直接忽略，不计为“不可用来源”；
- 自动抽样未走通首页、详情、播放地址或媒体探测：仅记为待验证或降序依据，不隐藏整个来源；
- 用户真实播放成功或失败：作为最高优先级证据，播放成功可以覆盖自动抽样的不确定结果。

当前配置共 122 个站点，其中 95 个属于 Android/未知桌面运行时并按平台忽略，27 个进入桌面端自动检测。最新抽样结果为 5 个已验证、2 个降级、20 个待验证、0 个阻断。网盘未登录、目录型来源和单条线路失败不再判定为整个来源不可用。

### 3.4 当前夸克播放事实

已抽样验证一条夸克极速线路最终媒体为：

- MP4 容器；
- H.264 High 视频；
- AAC 音频；
- 3840×2160；
- 依赖 Cookie、Referer 和 User-Agent。

日志中出现多次 `proxy.chunk.download.incomplete`，当前问题更可能与：

- Range 分段请求；
- HTTP 206；
- 请求头透传；
- 代理分片；
- 大文件拖动；

有关，而不一定是媒体编码本身不兼容。

### 3.5 当前网盘登录事实

CatVod 服务已经提供：

- 登录任务创建；
- 二维码返回；
- 登录状态轮询；
- 登录取消；
- Cookie 或凭据保存；
- 登录状态检测；
- 凭据加密存储。

当前主要缺口是 macOS 主界面的产品化封装，而不是底层能力完全缺失。
