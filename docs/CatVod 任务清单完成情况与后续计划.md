## 6. 后续建议顺序

后续任务统一按 `待完成事项与优先级.md` 执行。

### P0：当前版本必须收口

1. 重新生成包含多网盘、弹幕叠层和目录导航功能的 x64/arm64 安装包，完成六种网盘真实扫码、鉴权失败提示、清除凭据和登录后续播验收；
2. 在普通 macOS GUI、Apple Silicon 和干净机器完成内置播放器、BrowserSniffer 与 CatVod 回归；
3. 使用真实网盘或本地代理媒体验证 Range、拖动、HLS 子资源、动态端口和服务重启；
4. 使用真实弹幕/字幕样本验收弹幕层、字幕加载和高弹幕量表现；
5. 完成版本目录、manifest、候选版本、网络、登录任务和数据库异常的故障注入；
6. 同步 README、测试基线和发布检查项。

### P1：核心体验和正式发布

1. 真实多层网盘文件树、分页和文件播放样本验收；
2. 真实字幕/弹幕样本验收和高弹幕量性能观察；
3. macOS 正式签名、公证和桌面应用自动更新；
4. 插件数字签名、候选观察期和长期失败自动回滚；
5. Windows、Linux 实机打包、安装、播放和升级闭环。

### P2：独立能力

DLNA、直播/EPG/时移、短剧和漫画保持独立迭代，不混入当前点播闭环。

### 明确不做或近期暂缓

- 不再开发 Python Spider/Sidecar 或新的 Spider 运行时；
- Android Dex/JAR Spider、Android Bridge 和批量替代实现暂不实施；
- 近期不扩大 Drpy、XYQ、XBPQ、CatOpen、Alist、T4 等规则兼容样本，也不为单个失效站点持续补充专用加密、验证码或浏览器宿主能力；
- 已实现运行时继续保留，仅修复影响核心用户和安全性的明确缺陷。
