## 1. 使用说明

### 1.1 优先级

- **P0**：首期必须完成，形成“服务启动—站点加载—搜索—详情—播放”的最小业务闭环。
- **P1**：首期稳定后实施，完善动态筛选、配置中心、网盘账号、字幕弹幕等能力。
- **P2**：后续增强，包括直播、短剧、漫剧等专用体验和更完整的更新安全体系。

### 1.2 状态标记

- `□` 未开始
- `◐` 进行中
- `■` 已完成
- `△` 阻塞
- `—` 方案替代 / 暂缓

### 1.3 完成定义

单项任务标记为完成前，必须同时满足：

1. 代码已提交并通过 TypeScript 类型检查；
2. 相关单元测试或集成测试已通过；
3. 涉及界面的任务已完成实际页面走查；
4. 涉及播放链路的任务已使用真实播放源验证；
5. 未引入对现有 HTTP、Drpy、T4、CatOpen 等运行时的回归问题；
6. 相关日志中不得出现明文 Cookie、Token、密码等敏感信息。

# 9. 主要风险与控制措施

| 风险 | 影响 | 控制措施 |
|---|---|---|
| 远程 JS 拥有完整 Node 权限 | 文件、网络和凭据安全 | 独立进程、最少环境、localhost、版本审核 |
| MD5 与 JS 同源 | 不能证明代码可信 | SHA-256 审计、候选测试、人工激活、回滚 |
| 79 个站点全部检测 | 启动慢、请求过多、触发限制 | 服务级检测 + 子站点按需检测 |
| 动态端口写入图片和播放 URL | 重启后地址失效 | 稳定本地网关和逻辑标识持久化 |
| 豆瓣等首页无详情和播放 | 点击失败 | discovery 类型转全局搜索 |
| 分类名称不等于分类 ID | 分类请求错误 | SourceCategory 模型分离 ID 和名称 |
| 工具和直播混入影视页面 | 界面混乱、调用链错误 | contentType 分类、首期白名单和专用路由 |
| 远程配置变化 | 站点突然失效或变化 | 缓存配置、状态提示、异常降级和审计 |
| CatVod 更新破坏兼容性 | 无法启动或播放 | 候选版本冒烟、保留旧版、快速回滚 |
